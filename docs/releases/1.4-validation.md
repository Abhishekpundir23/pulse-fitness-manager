Counts after upgrade: 7 settings, 2 plans, 2 members, 3 memberships, 4 payments, 2 attendance records and 36 expenses. SQLite integrity and foreign-key checks passed, as did cold launch without crash-buffer errors.

Install the APK **over the existing app**. Do not uninstall or clear storage. A normal update does not require restoring a backup. These tests used synthetic records and isolated emulators; the friend's physical phone has not yet run this release.

All fields in all seven restored tables matched the archive: 7 settings, 3 plans, 24 members, 24 memberships, 24 payments, 65 attendance entries and 12 expenses. SQLite integrity and foreign-key checks passed. This fixture contained no photos.

The first 1.4 candidate, with identical backup/database code, additionally passed:

## Production AAB and 16 KB verification

Bundletool validated the final AAB. Inspection confirmed target API 36, optional camera/autofocus, disabled automatic backup and the packaged exclusions across all nine storage domains for legacy backup, cloud backup and device transfer. Broad photo/video access, external-storage, microphone and overlay permissions are absent.

The bundle requests `PAGE_ALIGNMENT_16K`; its generated APK passed 16 KB ZIP alignment. All **44 ARM64/x86-64 libraries** passed native LOAD alignment. A generated APK signed with an isolated test key ran on API 36 with `getconf PAGE_SIZE = 16384`, explicitly setting `bionic.linker.16kb.app_compat.enabled=false` and `pm.16kb.app_compat.disabled=true`. There was no compatibility dialog, linker error or crash. Offline gym setup, a five-month ₹1,799.50 custom plan, reports, attendance writes and restart persistence passed. SQLite integrity and foreign-key checks passed. Its Hermes bundle SHA-256 matched the signed release APK: `77d844c40787d0e97d7153dd314d3f2f78465e71318c5500c6d8a72aab7471d6`.

**Retained diagnostic:** 38 libraries fail the strict arithmetic check for a 16 KB-aligned GNU RELRO end. Independent ELF parsing and LLVM objdump agreed on all 44 libraries and 134 LOAD headers. All 38 flagged RELRO ranges exactly cover their corresponding writable LOAD; rounding their protection boundaries overlaps **zero bytes of any writable LOAD payload**, including BSS. Their rounded tails fall in padding before the next writable mapping. This explains why the documented writable-tail crash hazard was not demonstrated here; it does not turn the arithmetic warnings into passes. Compatibility-off runtime tests passed separately.

The range analysis follows the [Android page-size guidance](https://developer.android.com/guide/practices/page-sizes#relro) and [pinned Bionic page-rounding implementation](https://android.googlesource.com/platform/bionic/+/731631f300090436d7f5df80d50b6275c8c60a93/linker/linker_phdr.cpp#1376). Untested native paths and physical-device variation remain outside this evidence. Google Play's own validation and pre-launch report still need review after upload. The generated test-key APK is not an upgrade artifact and is excluded from the delivery pack.
